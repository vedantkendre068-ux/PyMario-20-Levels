
# 20-Mission Platformer Game

Hey! I am a 16-year-old student, and I built this 2D platformer game using Python and Pygame. I have been teaching myself how to code for about 2 years now by watching a lot of YouTube tutorials and following along with coding channels. 

This game is heavily inspired by classic Mario games, where you run, jump over gaps, collect coins, stomp on enemies, and try to reach the exit door to beat the level. I spent around 5 to 7 weeks working on this project. Whenever I ran into weird bugs or got stuck on tricky logic, I searched the internet, read through documentation, and used online resources to figure out solutions step by step. I also didn't design all the map layouts entirely on my own—I took help and inspiration from examples and designs I found online while building the levels.

The craziest part about this project is that I do not have a PC, so I coded and tested the entire thing directly on my smartphone using the Pydroid app. Writing hundreds of lines of code and fixing bugs on a tiny touch keyboard was honestly really frustrating at times, but it forced me to really understand how things like game loops, jump gravity, and collision checks actually work. 

I put together 20 different levels for the game, added an on-screen touch controller so it can be played right on a phone screen, and also set up keyboard controls (Arrow Keys / WASD / Space) so anyone on a computer can test it out. I even made a smart enemy that remembers where the player lands the most and tries to place traps to catch you off guard. 

If you want to play it on PC, just make sure you have Python and Pygame installed (`pip install pygame`), download the code, and run `python Main.py`. 

Since I am self-taught and still learning new things every day, I would really appreciate any feedback, tips, or advice on how to improve my code!
